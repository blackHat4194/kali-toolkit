# Security Policy

## Supported Versions

Security fixes are generally intended for the latest version on the default branch. No formal release support policy is currently guaranteed.

## Reporting a Vulnerability

Please report suspected vulnerabilities privately to the repository maintainer when a private reporting channel is available.

Include:
- A concise description of the issue
- Steps to reproduce it
- The affected script or component
- Potential impact and suggested mitigation

Avoid publishing sensitive exploit details before the issue has been reviewed.

## Safe Usage

- Review commands before running them.
- Do not run the toolkit as root unless a specific, reviewed task genuinely requires elevated privileges.
- Test destructive operations in a disposable directory.
- Review third-party repositories before executing their code.
- Use security tools only with explicit authorization.

The toolkit is provided without a guarantee that every operation is safe for every environment.
